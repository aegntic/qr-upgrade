# Runtime data flow — 20 September 2026

This is an engineering inventory, not approved privacy policy or certification.

- Web rendering, QR payloads, uploads and scan decoding remain local. Explicit browser saves persist the draft, complete artifact and five previous versions in IndexedDB. They may contain Wi-Fi passwords or contact details. Local archive is reversible; clearing site data removes copies.
- Only an explicitly submitted artwork prompt (8–800 characters) and selected style reach Vercel's server proxy and Cloudflare Workers AI FLUX.1 Schnell. The app does not store prompts. Never claim provider-side zero retention without contractual evidence.
- Generated JPEGs are stored briefly in project-specific D1. Owner cookies bind retrieval; a daily salted network HMAC enforces quotas without storing raw IP addresses. The cookie is HttpOnly, SameSite Strict, Secure in production and renewed for two hours before generation. Retrieval is unavailable after one hour. Hourly cleanup deletes image bytes within two hours and quota metadata after three days. An aborted browser request may still finish generation and consume its allowance.
- Atomic D1 reservations enforce three generation attempts per network per UTC day, 50 globally. A shared office network shares its allowance. A server-only service secret protects all Worker endpoints. Public image creation is available only through the origin-checked, bounded proxy. No prompt, QR content or secret is logged by application code. Hosting infrastructure may retain separate access logs; review platform retention and access.
- Optional Google sign-in is implemented but disabled without Google OAuth client credentials. PKCE/state/nonce, verified Google identity, HttpOnly signed session, canonical callback and same-origin writes protect access. No OAuth tokens go to browser storage. Signed sessions last seven days; centralized revocation/offboarding is not yet implemented.
- Optional cloud saves use D1 metadata scoped to the authenticated Google subject hash, and private R2 JSON objects. Save is explicit, limited to 3 MB/design and 50 designs/account including archives. Objects contain destination, uploaded image, portrait and rendered PNG; SVG and client-supplied scan assertions are omitted. Reopening rerenders and revalidates. No public R2 URL or hosted landing page is created. A cloud copy has no version history, automatic sync, permanent deletion or tenant/team controls yet.
- Updates publish a new private object and compare the previous pointer before replacing metadata; failed writes retain the old version. Rare terminated reservations may consume quota until operator reconciliation. Operational backup/restore, orphan reconciliation and rights-request procedures must be completed before enterprise account rollout.

Active runtime suppliers: Vercel (web/proxy), Cloudflare (DNS, Workers AI, D1 and private R2). Google becomes an authentication supplier only when OAuth is enabled. No billing/analytics supplier is active. Suppliers, processing locations, data agreements and policy notices need accountable owner approval; these technical controls do not establish SOC 2, ISO 27001 or legal compliance.
