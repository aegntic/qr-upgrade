# Scan the art

Two 30-second Remotion compositions share six scenes and actual product exports. They are captioned and silent. The visual frames are generated from QRUpgrade's own editor, existing artwork and campaign-kit output. No customer testimony, award, native listing or physical-phone scan is simulated.

Run `npm install --ignore-scripts` here, then `npm run landscape` and `npm run portrait`. Chrome/Chromium is required. For an existing browser installation pass Remotion's `--browser-executable` option. `public/asset-evidence.json` records the captured product state and image decoder checks. Assets are copies specifically for this project and contain only the public QRUpgrade destination.

The six five-second scenes are: artwork, actual editor, digital checks, campaign kit, another artwork and creation CTA. Replace a scene with a real phone scan when that footage is available. Voiceover can be added after ElevenLabs access and voice selection; the silent film is intentionally usable independently. Social platforms may recompress the video, so test a QR frame after upload before inviting people to scan it.

Creative basis: AKCodez/promo-video-skill (demo-first structure, two formats and metallic shine); selected Higgsfield guidance informs future scene variations. All motion here is deterministic Remotion frame-based animation. No external generation service was called.
